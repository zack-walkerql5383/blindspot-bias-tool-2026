## What blindspot does

blindspot helps users notice behavioral and cognitive bias patterns before those patterns affect a decision. It combines a bias profile with prompts delivered at the point where a choice is being considered.

The tool supports two settings: trading and everyday decision-making. In either context, it provides a structured pause for checking assumptions and approaching choices more deliberately, whether the situation is fast-moving or part of a normal routine.

---

## Capabilities

- Builds a bias profile to highlight repeated cognitive tendencies
- Delivers an intervention prompt as a decision is about to occur
- Provides a Trading mode for market-related decisions
- Includes an Everyday mode for broader personal choices
- Runs on the web without requiring a platform-specific application
- Supports reflection and review rather than automating decisions
- Uses a lightweight workflow suited to quick checks during active decisions

## Using blindspot

First create or review the bias profile. Next, select the mode that fits the decision you are examining.

A standard session looks like this:

1. Launch blindspot in a browser.
2. Complete the bias profiling process.
3. Choose Trading mode or Everyday mode.
4. Read the intervention prompt when the relevant decision point is reached.
5. Use the prompt as a check-in before proceeding.

In trading scenarios, run the check before placing or modifying an action. In everyday scenarios, use it for purchases, planning, communication, and other routine decisions where bias could affect the result.
